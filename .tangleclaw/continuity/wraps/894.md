## Landmines
- Native Next.js Server Components passing Date objects to Client Components cross the boundary as UTC timestamps. If a UTC Date initialized at midnight on the server is rendered in a local-time UI component on a client physically located in a negative timezone (like PST), it will silently shift backwards a day.
- `react-day-picker` v9 CSS drops pseudo-element overrides on `[disabled]` standard button states. Use native `text-decoration` or manually target pointer events via custom modifiers.
- iMessage link previews require strict 1.91:1 OpenGraph image aspects and sub-300KB JPEGs; slightly larger images or PNG formats fail silently.
